# Practice

> It's recommended to use the cloud setup from Lab 1 for faster cloning and building.

1. Deploy DefectDojo server with docker compose

    ```bash
    git clone --depth 1 https://github.com/DefectDojo/django-DefectDojo
    cd django-DefectDojo
    docker compose build && docker compose up -d
    docker compose logs -f initializer | grep "Admin password:"
    # Access on localhost:8080
    ```

1. Clone three vulnerable-by-design projects (to be used for testing)

    ```bash
    # Vulpy: Flask (Python) WebApp with SQLite database.
    git clone https://github.com/fportantier/vulpy
    rm -rf vulpy/.git

    # DVNA: Express (NodeJS) WebApp with MySQL database.
    git clone https://github.com/appsecco/dvna
    rm -rf dvna/.git

    # DVCA: C Program with utilities to read and process images.
    git clone https://github.com/hardik05/Damn_Vulnerable_C_Program
    mv Damn_Vulnerable_C_Program dvca
    rm -rf dvca/.git
    ```

1. Install 3 SAST tools ([Bandit](https://github.com/PyCQA/bandit), [NjsScan](https://github.com/ajinabraham/njsscan), [FlawFinder](https://github.com/david-a-wheeler/flawfinder)) in a Python virtual environment.

    ```bash
    python3 -m venv venv
    source venv/bin/activate
    pip install bandit njsscan flawfinder
    ```

## Task 1

1. Use the three SAST tools to scan the three projects. Produce all reports **in [SARIF](https://docs.oasis-open.org/sarif/sarif/v2.0/csprd01/sarif-v2.0-csprd01.html) format**.

2. Write and use a script (Python/BASH) to automatically import scan reports  to DefectDojo via its API.

3. Show screenshots of imported findings in the UI and inspect one finding.

4. Generate and attach a PDF report with the findings list across the three projects.
