# Defenses Against Memory Exploits

Two general approaches of protection against memory exploits:

- **Secure Coding**: detecting/preventing memory-related bugs at the source code level.

  - Enforcing Secure Coding Standards/Guidelines (e.g., MISRA C/C++, SEI CERT C)
  - Using SAST Tools (e.g., PVS-Studio) & Compiler modules (e.g., AddressSanitizer)
  - Manual & AI-Assisted Code Reviews

- **Binary Security**: integrate defenses at the OS, compiler, and hardware levels.

  - Address Space Layout Randomization (ASLR)
  - Stack Protector (Canary)
  - No-eXecute bit / Data Execution Prevention
  - Control Flow Integrity / Control Flow Guard
  - Guard Pages
  - (Kernel) Page Table Isolations
