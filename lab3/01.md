# Memory Safety

> <https://en.wikipedia.org/wiki/Memory_safety>

Memory safety is the state of being protected from various software bugs and security vulnerabilities when accesing objects in memory.

- [Top 25 CWEs](https://cwe.mitre.org/top25/) include multiple memory-related vulnerabilities: buffer overflows, use-after-free, null pointer dereference, and out-of-bound read/write.

- C/C++ languages allow direct access to memory with pointer arithmetics, they also do not perform garbage collection, and are thus considered memory-unsafe.

## Practice

1. Install `valgrind`

    ```bash
    sudo apt update && sudo apt install valgrind
    ```

1. Inspect the provided `program1.c`

    ```c
    cd /app/workshop/task1
    nano program1.c
    ```

1. Compile and run the program

    ```bash
    gcc -Wall -Werror -g -std=c99 -o program1 -O0 program1.c
    ./program1
    ```

1. Run the program with `valgrind` to check for memory leaks.

    ```bash
    valgrind --leak-check=full ./program1
    ```
