# Instructions for MacOS Users

MacOS users may need a Linux VM or a cloud instance to complete this lab. Two options are recommended:

## Cloud VM

Follow the instructions from `lab1` to run an ubuntu cloud instance (amd64 architecture) and SSH to it from the terminal environment.

## Local VM

Instructions to run `labenv` in a local VM with `qemu` and `lima`.

1. Install needed tools with HomeBrew

    ```bash
    brew install qemu
    brew install lima
    ```

2. Download and extract VM image from GitHub

    ```bash
    wget https://github.com/Sh3b0/interactive-labs/releases/download/boxes/labenv-libvirt-amd64.box

    tar xzvf ./labenv-libvirt-amd64.box
    
    cd libvirt && ls # should see a box.img file
    ```

3. Adjust paths in `labenv.yaml` following inline comments in the file

4. Start the VM

    ```bash
    # Make sure to stop docker-based deployment to avoid port conflicts
    docker compose down && docker container prune -f

    # Start the VM from YAML template
    limactl start ./labenv.yaml # Press enter to proceed

    # Watch boot logs in another terminal
    tail -f ~/.lima/labenv/serial*.log
    ```

5. Helpful commands (check `limactl -h`)

    ```bash
    limactl list           # List VMs
    limactl shell labenv   # SSH into the VM
    limactl restart labenv # Restart the VM
    limactl stop labenv    # Stop the VM
    limactl delete labenv  # Delete the VM
    limactl prune          # Prune garbage objects
    limactl start-at-login --enabled false # Disable VM autostart
    ```
