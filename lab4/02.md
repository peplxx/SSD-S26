# Session Management in Modern Web Applications

- **Server Sessions:** a stateful way in which the web server maintains a dynamic storage (e.g., a dictionary) with information about active client sessions (indexed by a session ID).

- **JSON Web Tokens (JWTs):** a stateless way in which the web server provides clients with a cryptographically signed [token](https://www.jwt.io/introduction#what-is-json-web-token-structure) upon successful login and verifies it for authorization.

## Examples with Python+Flask

> Check the full working examples in the provided `session-examples` directory.

- Stateful logic: uses a global `session` dict. Flask handles serializing and signing it into a cookie.

    ```python
    @app.route('/login', methods=['POST'])
    def login():
        username = request.form['username']
        password = request.form['password']
        
        if username in USERS and USERS[username] == password:
            session['user'] = username
            session['role'] = 'admin' if username == 'admin' else 'user'
            return redirect(url_for('home'))
        
        return render_template_string(HTML_TEMPLATE, error="Invalid credentials")
    ```

- Stateless logic: sends JWT on successful login, to be verified when accessing protected resources.

    ```python
    @app.route('/login', methods=['POST'])
    def login():
        data = request.get_json()
        username = data.get('username')
        password = data.get('password')

        if username in USERS and USERS[username] == password:
            payload = {
                'sub': username,
                'role': 'admin' if username == 'admin' else 'user',
                'exp': datetime.datetime.utcnow() + datetime.timedelta(minutes=30)
            }
            token = jwt.encode(payload, SECRET_KEY, algorithm='HS256')
            
            return jsonify({'token': token})
        
        return jsonify({'message': 'Invalid credentials'}), 401
    ```

## Summary

| Feature | Server-Side Session (Stateful) | Client-Side JWT (Stateless) |
| :--- | :--- | :--- |
| **Storage** | Cookie (`HttpOnly`, `Secure`) | `localStorage` or Cookie |
| **State** | State stored on Server (Memory/Redis/DB) | State contained inside the Token |
| **Logout** | Easy: delete server session | Difficult: token remains valid until expiry |
| **Security** | Proteced from XSS (if HttpOnly) | Vulnerable to XSS (if in localStorage) |
| **Best For** | Traditional Web Apps | SPAs, Mobile Apps, APIs |
